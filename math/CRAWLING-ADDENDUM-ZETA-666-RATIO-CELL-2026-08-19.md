## Zeta phasor ingredients

On the critical-line harmonic picture, a Dirichlet phasor has the form

```text
z_n(t) = n^(-1/2) exp(-i t log n)
```

up to the additional completion/Riemann-Siegel structure required for rigorous use near the critical strip.

Each individual phasor is nonzero. A function zero is a cancellation/resultant condition, not the statement that the constituent terms occupy zero.

## Three-term relational cycle

Choose three positive indices/labels `a,b,c`. Their pairwise phase differences are generated by logarithmic ratios:

```text
theta_ab = t log(b/a)
theta_bc = t log(c/b)
theta_ca = t log(a/c).
```

The directed cycle closes exactly because

```text
(b/a)(c/b)(a/c) = 1.
```

Taking logs:

```text
log(b/a) + log(c/b) + log(a/c) = log(1) = 0.
```

Therefore

```text
theta_ab + theta_bc + theta_ca = 0.
```

This supplies an exact multiplicative/logarithmic `333 -> 000` closure relation without imposing a 120-degree phase spacing.

Important: this ratio-cycle closure is not the same as equal-phasor vector cancellation. It is a closure of directed log-ratios / phase differences.

## Reverse cycle and the six

Every directed relation has an inverse:

```text
a -> b  <->  b -> a
b -> c  <->  c -> b
c -> a  <->  a -> c.
```

The reverse phase satisfies

```text
theta_ba = -theta_ab
```

and similarly for the other two edges.

Thus three undirected pair relations generate six directed relations:

```text
3 pair relations * 2 orientations = 6 directed relations.
```

The current candidate `666` cell is therefore a bidirectional triangular multiplicative relation:

```text
333_+ : a -> b -> c -> a
333_- : a <- b <- c <- a
666   : 333_+ plus 333_-.
```

Both directed cycles close multiplicatively to `1` and logarithmically to `0`.

## Critical-half amplitude relation

For critical-line amplitudes

```text
|z_n| = n^(-1/2),
```

the amplitude ratio on a directed edge is

```text
|z_b| / |z_a| = (b/a)^(-1/2).
```

The reverse ratio is

```text
|z_a| / |z_b| = (a/b)^(-1/2).
```

Their product is exactly

```text
(b/a)^(-1/2) (a/b)^(-1/2) = 1.
```

Thus the half exponent supplies reciprocal balance between opposite directed relations.

## Off-critical imbalance

Write

```text
s = 1/2 + delta + i t.
```

The corresponding directed amplitude ratio becomes

```text
(b/a)^(-1/2-delta).
```

The reflected counterpart carries the opposite transverse displacement and therefore

```text
(b/a)^(-1/2+delta).
```

Their ratio is

```text
(b/a)^(2 delta).
```

At

```text

```

this imbalance ratio is exactly `1`.

A convenient logarithmic pressure/imbalance coordinate is

```text
P_ab(delta) = 2 delta log(b/a).
```

It changes sign under edge reversal and vanishes for every nontrivial edge when `delta=0`.

## Relation to the RH involution

The separately frozen RH involution is

```text
J(s) = 1 - conjugate(s).
```

For



## What this does not prove

The identities above are exact for multiplicative ratios and logarithmic phase differences. They do not establish that the full completed xi/zeta zero condition decomposes into independent `666` triangular cells, nor that global cancellation is possible only when every cell has zero transverse imbalance.

That missing implication is the RH-sized problem.
